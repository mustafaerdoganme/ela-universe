# ELA Experiential Learning Universe

ELA'nın dernek ve akademi yapısını yedi adalık bir deniz yolculuğu olarak anlatan tanıtım oyunu (v38).

Canlı site: https://mustafaerdoganme.github.io/ela-universe/

Statik bir sitedir; derleme gerekmez. Yerelde denemek için bu klasörde
`python3 -m http.server 8000` çalıştırıp http://localhost:8000 adresini açın
(index.html'e çift tıklamak çalışmaz, tarayıcılar file:// adresinde modülleri engeller).
İlerleme ziyaretçinin tarayıcısında saklanır. Gerçek başvuru göndermez, resmî unvan vermez.
